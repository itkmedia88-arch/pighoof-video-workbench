# AI新个体 · 视频工作台

这里是公开官网，展示八种视频创作流程。当前仅单图纯产品视频开放邀请码试用，其他七项尚未开放。

[进入产品视频制作网站](https://anything-unedited-harmonics.ngrok-free.dev/)

试用流程：自己注册 → 使用管理员提供的邀请码激活 → 上传一张产品图 → 填写产品名称和真实卖点 → 核对方案及费用并确认生成 → 播放、下载成片。

当前试用参数固定为 4 秒、480p、9:16，仅展示产品，不含人物出镜、数字人或声音克隆。生成次数由管理员分配，不提供无限次免费生成。素材经 ngrok 转发至管理员电脑，只有确认生成后才发送至火山方舟。

GitHub Pages 托管这个静态官网，制作服务目前运行在管理员电脑上。管理员电脑需要保持开机联网；服务离线时请联系管理员。访客无需在自己的电脑安装制作软件。

官网只发布静态页面和原创流程示意图；不包含后台服务、密钥、私人素材、账号数据库或任务数据。
